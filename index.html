03 / PRODUCT INTELLIGENCE

Cortellis Product Intelligence（CPI）

拓展業務，打造穩健的供應鏈。以整合全球上市藥品、原料藥製造商、專利、銷售與市場情報的單一平台，支持產品選題、學名藥上市、供應商搜尋及商業評估。

產品與市場機會

利用 Product Selector 依上市狀態、獨占權喪失、市場潛力與競爭條件篩選候選產品，並評估產品組合。

上市限制日期預測

Constraint Date Forecast 綜合專利、獨占權與 SPC，協助評估不同國家學名藥的可能上市時機；預測不等於法律意見。

製造商與供應鏈

Company Selector 搜尋 API、製劑製造商、供應商與合作夥伴，參考產品組合及可取得的監管資料。

銷售與 API 消耗量

分析製劑銷售額及估算的 API 消耗量，協助衡量市場規模、產品機會與潛在供應需求。

專利與競爭情報

結合專利家族、SPC、專利訴訟及專利強度分析，支持產品上市時程與競爭評估。

進出口與藥品短缺

利用可取得的海關資料、進出口商及單一產品短缺狀態，補充供應鏈風險分析。

05 / COMPETITIVE INTELLIGENCE

Cortellis Competitive Intelligence（CCI）

從藥物發現到上市與商業化，以研發管線、競爭態勢及預測分析，支持產品組合策略、資產評估、投資及授權決策。

研發管線追蹤

依疾病、靶點、MoA、公司及開發階段建立競爭版圖，辨識早期資產及新興競爭者。

DTSR 預測

Drug Timeline & Success Rates：比較藥物開發時程、成功機率及預期上市時間，支持情境分析。

銷售預測

結合共識與專有預測分析，依品牌、地區、治療領域等評估商業潛力。

SWOT 分析

分析產品優勢、劣勢、機會及威脅，協助差異化定位及策略討論。

交易與盡職調查

交叉檢視藥物、公司、臨床、專利與交易情報，評估合作與授權標的。

API 與 AI 分析

可依授權使用結構化資料介面及適用的 AI 搜尋工作流程；API、資料饋送及模型訓練權利須個別確認。

08 / PRACTICAL USE CASES

市場情報的實務應用：PITDC 討論重點

依 2026 年 10 月 8 日 PITDC 交流整理，呈現客戶實際關注的決策問題；以下為應用示例與待確認事項，不代表所有功能已包含於現有訂閱。

東南亞市場進入評估

關注新加坡、馬來西亞、泰國、越南的藥品市場規模與競爭。需確認個別國家資料覆蓋，不能將 Rest of World 匯總直接當作東南亞銷售額。

API 供應鏈與進出口

利用海關申報辨識進出口商、產品及物流線索。API 與製劑應分別篩選；重量、件數、淨重與毛重不可直接視為活性成分數量。

藥品定價與報銷分析

比較相同劑型、規格、包裝、幣別及通路下的價格，評估定價策略與市場准入；不宜用總銷售額除以單一包裝價格推算銷量。

Drug Shortage 商業機會

由個別短缺狀態延伸至供應缺口、潛在學名藥機會及 API 風險分析；完整短缺清單的直接匯出功能仍需向原廠確認。

2026/10/08 會議狀態：PITDC 將先內部評估 CPI 續訂及新增模組需求；US Market、拉美單國資料及 Global Price Trend 的授權與價格尚待確認，當次未形成採購決議。AI 助手的預計上線時間與適用範圍亦非正式承諾。
